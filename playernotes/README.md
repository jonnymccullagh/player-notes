# Player Notes

This mod adds local player notes for the multiplayer lobby.

Current features:
- `Notes` button in the lobby opens a dialog to add, view and delete notes
- Hovering a player in the lobby player list shows any saved notes immediately as a tooltip
- Clicking an assigned player name in Game Setup opens that player's notes dialog

Notes are stored locally in `moddata/player-notes.json`.

To test with a development build, load the mod after `0ad`.
